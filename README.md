# Bellescapes — Editorial Blog Drafts

Long-form editorial travel writing for **BELLESCAPES.FR** — a slow-travel magazine covering France and its neighbours, written in English for a Northern-European / Anglophone audience.

The focus is on the France (and adjacent Spain) that guidebooks skip: regional fiestas, working towns, Roman stone, river beaches, mountain railway lines. Every piece is written as a first-person field dispatch — no listicle filler, no generic "top 10" framing.

## Format

Each file is Markdown with YAML front matter:

```yaml
---
title: "..."
slug: kebab-case-slug
region: ...
tags: [ ... ]
featured: false
date: 2026-08-25
---
```

Bodies use `###` subheads, and `[IMAGE]` marks where a full-bleed photograph belongs (no text overlaid on images — photos carry the page).

## Editorial rules

- English-language, editorial travel magazine voice (Nat Geo × POV journal).
- Real, verifiable places and details only — no invented venues, prices, or timetables.
- Anti-cliché: no "hidden gem" clichés, no listicle scaffolding.
- Affiliate monetisation means every published page needs an affiliate disclosure from day one.
